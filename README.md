 # 🌤️ Weather App

A modern weather application built with **Flutter** that allows users to search for cities and view real-time weather information in a simple and user-friendly interface.

## ✨ Features

* 🔍 Search for any city and get its current weather.
* 🌡️ Display current temperature and weather conditions.
* 🌤️ Dynamic UI that changes based on the weather condition.
* 🎨 Dynamic colors and backgrounds according to the current weather.
* 📍 Display weather information for different locations.
* ⚡ Fast and responsive user interface.
* 📱 Clean and modern Flutter UI.

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Cubit / Bloc** for State Management
* **REST API** for fetching weather data
* **HTTP** for API requests

While building this project, I practiced:

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your machine.

### Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/weather_app.git
```

Navigate to the project:

```bash
cd weather_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## 🔑 API

This application uses a weather API to retrieve current weather information.

> Make sure to add your API key to the appropriate configuration before running the project.
